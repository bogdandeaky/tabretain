How to auto-save your Chrome tabs

Chrome can reopen tabs after a normal restart, but it does not keep a history of your sessions that you can go back to. Here is what you can do.

Built in: bookmark all tabs

Press Ctrl+Shift+D (Cmd+Shift+D on Mac) to bookmark every tab in the current window into one folder. It is reliable but manual: you have to remember to do it, and it covers one window at a time.

Built in: continue where you left off

Settings → On start-up → Continue where you left off reopens your last session. It keeps only one session, and it can lose it if Chrome's session files are damaged.

Automatic: a tab saver extension

An extension can save every normal window and tab on a timer and whenever tabs change, keep a dated history of snapshots, and let you name the sessions you want to keep. Look for one that stores data locally, can export to a file, and does not need an account.

Good habits either way

  • Export important sessions to a file now and then. It survives a lost Chrome profile.
  • Each Chrome profile is separate. Protect each profile you use.
  • Incognito windows are not saved by Chrome or by well-behaved extensions.
