How to bulk download documents from a website

DocGrab downloads all PDFs and Office files linked on the current page in one click.

What to check first

  • Are the files linked on the page? If you can see links ending in .pdf, .docx, .xlsx or .pptx, they can be downloaded in bulk.
  • Are they spread over several pages? Most tools work one page at a time. Open each page and repeat.
  • Do you need to be logged in? Then use a tool that runs inside your browser, where you are already logged in.

Options

Manual: right-click → Save link as, for a handful of files.
Command line: wget -r -l1 -nd -A pdf,docx,xlsx,pptx URL for public pages.
Browser extension: lists the document links on the open page so you can tick the ones you want.

Tips

  • Save each batch in a folder named after the site, so files from different sources don't mix.
  • If some downloads fail, retry only those instead of downloading everything again.
