How to download all Word, Excel and PowerPoint files from a page

DocGrab downloads all Word, Excel and PowerPoint files linked on the current page in one click.

Find the links

Hover over a link. Your browser shows its address at the bottom left. Office files end in .doc/.docx, .xls/.xlsx, .ppt/.pptx or .csv.

Download only the type you need

If you only want the spreadsheets, filter by type before downloading. With wget that is -A xlsx,xls. In an extension, use its type filter.

Keep readable names

The link text usually describes the document better than the file address. A good tool uses that text for the file name when it names the document, and the address when it does not.
